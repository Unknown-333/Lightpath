# The WELCOME10 coupon barely changes the price

The WELCOME10 coupon is supposed to take 10% off the items. It hardly does anything.

To see it: add one Desk lamp ($39.00) to the cart, type WELCOME10 in the coupon box and press Checkout. The order total is $43.60. The same order without the coupon is $43.99. With 10% off the lamp it should be $40.09 ($35.10 for the lamp plus $4.99 shipping).

The shop runs with `npm run dev`; the page is at http://localhost:5173.

# Focus offers projects I've already finished

I click Focus at the top of the page and open the project menu. It lists projects I've already finished, mixed in with my open ones, so I have to scroll past done work to pick a project.

To see it: sign in, add a project "Kitchen remodel" and a project "Garden shed", mark "Garden shed" done, then click Focus and open the project menu ("Any project").

The app runs with `node dev.mjs` (API on port 3402, web on http://localhost:8402, user dev@tududi.test, password DevPass123!).

# Repeating tasks show the wrong time in Upcoming

I make a task that repeats every day and give it a due time of 3:30 PM. When I click Upcoming, the next days show that task at midnight instead of 3:30 PM. The task itself still says 3:30 PM when I open it.

To see it: sign in, add a task "Review Inbox" due today at 15:30, set it to repeat daily, then click Upcoming.

The app runs with `node dev.mjs` (API on port 3402, web on http://localhost:8402, user dev@tududi.test, password DevPass123!).

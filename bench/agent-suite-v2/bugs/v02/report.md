# My custom report lists a category I unchecked

In Reports I make a new custom report as a data table and untick "Food" in the category list. Food goes away. When I then turn on "Show empty rows" in Options, Food comes back as an empty row, although it's still unticked.

To see it: open the demo budget, go to Reports, Add new widget, New custom report, pick Data Table, untick Food, then Options, Show empty rows.

The app runs with `node dev.mjs` (web on http://localhost:8613, browser mode, no server). Click "Try the demo" for a budget with data.

# "One item per line" doesn't stay on

In Profile Settings, under Shortcuts, I tick "One item per line". The tick doesn't stay, and when I go to the Inbox and type two lines, I still get one item with both lines in it. After I reload the page, the setting is on and works.

To see it: sign in, open Profile Settings, click Shortcuts, tick "One item per line", click Inbox in the sidebar, type "Buy milk", Shift+Enter, "Buy bread", and click Add.

The app runs with `node dev.mjs` (API on port 3611, web on http://localhost:8611, user dev@tududi.test, password DevPass123!).

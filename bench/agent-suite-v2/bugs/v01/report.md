# My comments are signed "Unknown"

When I add a comment to a task, the comment shows "Unknown" as its author instead of me. I never filled in a name in my profile, I only signed up with my email.

To see it: sign in, open any task, write a comment and post it, then look at the name above the comment.

The app runs with `node dev.mjs` (API on port 3611, web on http://localhost:8611, user dev@tududi.test, password DevPass123!).

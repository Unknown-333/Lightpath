# @lightpath-dev/mcp

The MCP server of [Lightpath](https://github.com/Unknown-333/Lightpath#readme), so coding agents can ask which code ran for an action you just did in your app.

Run it with `npx -y @lightpath-dev/cli mcp`. Setup for Claude Code, Cursor, VS Code, and Kiro: [Ask your coding agent](https://github.com/Unknown-333/Lightpath#ask-your-coding-agent).

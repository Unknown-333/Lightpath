# @lightpath-dev/core

The mapping pipeline of [Lightpath](https://github.com/Unknown-333/Lightpath#readme): V8 coverage ranges to lines in your original source files, through source maps. Pure functions, no I/O.

You don't need this package directly; [`@lightpath-dev/cli`](https://www.npmjs.com/package/@lightpath-dev/cli) uses it.

# @lightpath-dev/protocol

Message schemas and the daemon client shared by the [Lightpath](https://github.com/Unknown-333/Lightpath#readme) agents, daemon, and editor. Format: [docs/PROTOCOL.md](https://github.com/Unknown-333/Lightpath/blob/main/docs/PROTOCOL.md).

You don't need this package directly; [`@lightpath-dev/cli`](https://www.npmjs.com/package/@lightpath-dev/cli) uses it.
